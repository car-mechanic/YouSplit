The Docker Compose setup is built for development, but is also used on a server:

- Postgres port `5432` is published on the host. It only needs to be reachable from the backend container.
- The frontend runs as Vite dev server instead of a production build.
- Default DB credentials (`yousplit`/`yousplit`) are in `docker-compose.yml`.

**Goal:** a production Compose variant (or profile) without the published DB port, with a built frontend, and credentials from `.env`. The add-on image (`Dockerfile.addon`) already serves a production build and can serve as a reference.
