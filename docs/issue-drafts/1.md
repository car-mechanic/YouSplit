The schema is created with `Base.metadata.create_all`, which never alters existing tables. New columns are patched in by `database.ensure_schema_updates()` (idempotent `ALTER TABLE … ADD COLUMN IF NOT EXISTS`, Postgres only).

That works for added nullable columns, but not for renames, type changes, constraints or data migrations.

**Goal:** introduce Alembic, generate a baseline migration matching the current schema, and replace `ensure_schema_updates()`.

**Watch out:** existing installations (Compose volume and the Home Assistant add-on in `/data/postgres`) must be stamped to the baseline, not migrated from scratch.
