`backend/main.py` allows exactly one CORS origin: `http://localhost:5173` (Vite dev server).

A dev server on another port (e.g. 5174) is blocked, and any deployment where frontend and API live on different origins fails.

**Goal:** make the allowed origins configurable via an environment variable (default: `http://localhost:5173`). The add-on serves frontend and API from the same origin and needs no CORS at all.
