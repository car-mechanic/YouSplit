`backend/bank_statement.py` has only been tested with synthetic PDFs.

**Known weak spots:**
- Debit/credit columns without a sign are guessed.
- No OCR: scanned statements don't work (by design, documented).
- Layouts of different German banks are untested.

**Goal:** test with real statements from several banks, add anonymized fixtures to the test suite, and fix the parser where it fails. The preview in the UI catches errors, so this is quality, not data loss.
