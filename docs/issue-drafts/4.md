Lists have no authentication. Anyone who knows a list's UUID can read and edit it. This is by design (no accounts, share by link), but it should be a conscious, documented trade-off.

**Options to evaluate:**
- Keep it, but document it clearly (README already warns)
- Optional per-list PIN or password
- Read-only share links next to edit links
- Rate limiting on list lookups

Relevant for any public deployment (Cloudflare tunnel, add-on port 8099 exposed to the internet).
